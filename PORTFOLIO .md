**COMPARATIVE ANALYSIS OF ANTIVIRUS, EDR AND ENDPOINT PROTECTION PLATFORMS.**

**INTRODUCTION**

* Nowadays, computers, laptops, and other devices are frequently targeted by cyberattacks. Attackers may use malware, ransomware, spyware, or stolen credentials to access a system. Endpoint security helps protect these devices from such threats.
* It helps organizations prevent threats, detect suspicious activities, and respond quickly when an attack occurs.
* There are different endpoint security solutions available.

  * Antivirus (AV)

    * Endpoint Detection and Response (EDR)
    * Endpoint Protection Platform (EPP)

**ANTIVIRUS (AV):**

* Antivirus is one of the most commonly used security tools. Its main job is to find and remove harmful software from a computer.
* For example, if a user downloads a file containing a known virus, the antivirus can identify it and either block or quarantine the file.

**Main functions:**

* Detects viruses and malware.
* Scans files and applications.
* Blocks suspicious files.
* Removes or quarantines infected files.
* Provides basic protection against common threats.

**Advantages:**

* Easy to install and use.
* Provides basic protection.
* Suitable for personal computers.
* Usually requires less technical knowledge.

**Limitations:**

* Traditional antivirus may not detect completely new threats.
* It provides limited information about how an attack happened.
* It has fewer investigation and response features than EDR.

**ENDPOINT DETECTION AND RESPONSE (EDR)**

* EDR is a more advanced endpoint security solution. Instead of only checking files, it continuously monitors what is happening on a device.
* For example, if an attacker gets into a computer and starts running unusual commands, EDR can notice this suspicious behaviour and alert the security team.

**Main functions**

* Continuously monitors endpoint activity.
* Detects unusual behaviour.
* Records security events.
* Helps investigate attacks.
* Supports threat hunting.
* Can isolate an infected device.
* Can automatically respond to certain threats.

**Advantages**

* Detects advanced and suspicious attacks.
* Gives detailed information about an incident.
* Helps security teams investigate attacks.
* Can respond quickly to threats.
* Useful for detecting ransomware and other advanced attacks.

**Limitations**

* More difficult to manage than antivirus.
* Requires trained security professionals.
* Can generate many alerts.
* May be more expensive.

**ENDPOINT PROTECTION PLATFORM (EPP)**

* EPP is a broader endpoint security solution. Instead of depending on only one security feature, it combines several protection technologies into a single platform.
* An EPP may include antivirus, malware protection, firewall, application control, device control, and other security features. Modern EPP solutions can also include EDR capabilities.

**Main functions**

* Malware and virus protection.
* Firewall protection.
* Application control.
* Device and USB control.
* Threat detection.
* Endpoint monitoring.
* Centralized security management.

**Advantages**

* Provides multiple layers of protection.
* Security can be managed from one platform.
* Suitable for organizations with many endpoints.
* Can combine prevention, detection, and response.
* Reduces the need to manage many separate security tools.

**Limitations**

* Can be more expensive than basic antivirus.
* Requires proper configuration.
* May be complex for small organizations.

**Simple Example**

Consider a company employee who receives an email containing a malicious file

**Antivirus**

* The antivirus scans the file and recognizes that it contains malware. It blocks or quarantines the file.

**EDR**

* Suppose the malware was not recognized immediately and started running. EDR monitors the activity and notices unusual behaviour, such as an unknown program accessing sensitive files. It alerts the security team and may isolate the computer.

**EPP**

* An EPP can provide several layers of protection. It may block the malicious file, control the application, monitor the endpoint, and use additional security controls to reduce the chance of a successful attack.

**CONCLUSION**

* Endpoint security has become an important part of cybersecurity because endpoints are common targets for attackers.
* Antivirus provides basic protection by detecting and removing malware. EDR goes further by continuously monitoring endpoint activities and helping security teams detect, investigate, and respond to suspicious behaviour.
* EPP provides a broader solution by combining different endpoint security technologies into one platform.
